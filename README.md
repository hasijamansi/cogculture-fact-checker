# AI-Powered PDF Fact Checker

## Project Overview
The AI-Powered PDF Fact Checker is a web application that analyses PDF documents, extracts factual claims, and checks them against information available through live web search.

The application helps users identify potentially inaccurate or false information in documents.

## Key Features
- Upload PDF documents.
- Extract factual claims, statistics, dates, and figures.
- Verify claims using web search.
- Classify claims as Verified, Inaccurate, False, or Unverifiable.
- Display explanations and supporting sources.
- Download verification results as a CSV file.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Tavily Search API
- PyPDF

## Installation and Setup

1. Clone the repository:
   `git clone https://github.com/hasijamansi/cogculture-fact-checker.git`

2. Install dependencies:
   `pip install -r requirements.txt`

3. Configure the required API keys using Streamlit secrets.

4. Run the application:
   `streamlit run app.py`
